# Mahreen untuk Anak Muda

Website sederhana yang memperkenalkan Mahreen Indonesia kepada generasi muda lewat tema **Berkarya untuk Indonesia**.

Dibuat oleh Sandhika Hamzah (Universitas Gunadarma) untuk Creative Challenge Mahreen Indonesia Internship Batch 2, posisi Website Development. Informasi dirangkum dari unggahan publik Mahreen Indonesia, Mei sampai September 2026.

> README lengkap (tugas, konsep, keputusan desain, dan cara memperbarui data) menyusul di tahap dokumentasi.

## Cara menjalankan

Tidak perlu instalasi. Klik dua kali `index.html`, atau jalankan server lokal:

```bash
python3 -m http.server 8000
```

lalu buka `http://localhost:8000`.

## Memperbarui konten

Semua konten ada di `js/data.js` sebagai objek `MAHREEN`, dan dirender oleh `js/main.js`.
